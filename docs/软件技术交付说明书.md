## 1. 项目概述

### 1.1 项目背景

AIVC 是一个面向 AI 风险投资领域的知识图谱系统，旨在追踪和可视化全球 AI 领域中 VC 机构、初创公司和投资人之间的投资关系网络。

### 1.2 核心目标

- 构建结构化的 AI 风投知识图谱
- 支持多源数据导入（XLSX 种子数据、RSS 新闻源、手动添加）
- 提供命令行查询和交互式可视化
- 实现每日自动增量更新
- 所有数据以 JSON 格式持久化，便于版本控制

### 1.3 技术选型

| 组件 | 技术 | 选型理由 |
|------|------|----------|
| 图数据结构 | NetworkX (MultiDiGraph) | 纯 Python，支持多边、有向图，无需外部数据库 |
| 数据校验 | Pydantic | 类型安全的数据模型，自动序列化 |
| 可视化 | Pyvis (Vis.js) | 生成独立 HTML 文件，零服务器依赖 |
| RSS 解析 | feedparser | 成熟的 RSS/Atom 解析库 |
| 网页抓取 | requests + BeautifulSoup4 | 轻量级 HTML 内容提取 |
| 部署 | Vercel | 静态 HTML 托管，免费方案 |
| CI/CD | GitHub Actions | 每日定时任务，免费（公开仓库） |
| 智能提取 | Claude Code（交互式） | 无需单独的 API 密钥，利用用户已有订阅 |

### 3.3 图谱特性

- **图类型：** 有向多重图（MultiDiGraph），支持同一对节点间的多条边
- **节点 ID 生成：** 确定性命名，`node_id("Andreessen Horowitz (a16z)")` → `"andreessen-horowitz-(a16z)"`
- **幂等合并：** 重复添加同一节点/边不会产生重复数据，已有非空字段不会被空值覆盖
- **边键规则：** `(edge_type, round, date)` 作为唯一键，支持同一机构对同一公司的多轮投资

## 4. 数据管道

### 4.1 初始化管道（一次性）

```
ai_vc_firms_worldwide.xlsx
  → scripts/seed.py
    → aivc/ingest.py（解析 XLSX 三个工作表）
      → 工作表1：81 家 VC 机构 + 投资组合
      → 工作表2：23 位知名投资人
      → 工作表3：新闻源（RSS 地址）
    → aivc/graph.py（构建图谱）
  → data/graph.json（约 418 节点、422 边）
```

### 4.2 每日增量更新管道

**阶段一：自动抓取（GitHub Actions，每日 UTC 8:00）**

```
触发：cron '0 8 * * *' 或手动 workflow_dispatch
  → scripts/update.py --fetch
    → aivc/ingest.py: get_news_sources()（从 XLSX 读取 RSS 源）
    → scrapers/rss_monitor.py: fetch_articles()
      → feedparser 解析 RSS
      → 正则匹配融资关键词（raises、funding、Series X 等）
      → BeautifulSoup 抓取全文
    → 去重（跳过已处理的 URL）
    → data/staging/raw_articles.json（原始文本，无 LLM）
    → data/state/processed_urls.json（状态更新）
    → git commit & push
```

**阶段二：智能提取（Claude Code 交互式会话）**

```
用户在 Claude Code 中请求提取
  → 读取 data/staging/raw_articles.json
  → 从每篇文章中提取交易信息
  → 写入 data/staging/pending_deals.json
```

**阶段三：审批合并**

```
scripts/update.py --approve
  → 加载 data/staging/pending_deals.json
  → 加载 data/graph.json
  → 创建快照 data/snapshots/graph_YYYYMMDD_HHMMSS.json
  → 幂等合并交易到图谱
  → 保存更新后的 data/graph.json
  → 重新生成 viz/output/graph.html → public/index.html
  → 清空暂存区
```

### 4.3 状态管理

`PipelineState` 类（`aivc/state.py`）追踪已处理的 URL：
- 每处理一个 URL 后立即持久化，支持崩溃恢复
- 防止同一篇文章被重复处理
- 存储位置：`data/state/processed_urls.json`

## 5. 可视化系统

### 5.1 技术栈

- **生成引擎：** Pyvis（Vis.js 的 Python 封装）
- **输出格式：** 独立 HTML 文件（约 748KB），内嵌 CSS/JS，零外部依赖
- **主题风格：** Bloomberg 终端暗色主题

### 5.2 视觉设计

**节点样式：**

| 类型 | 颜色 | 大小规则 |
|------|------|----------|
| VC 机构 | #FF8C00（琥珀色） | 按连接度缩放 |
| 初创公司 | #00D67E（终端绿） | 按连接度缩放 |
| 投资人 | #00BFFF（亮青色） | 按连接度缩放 |
| 最近 7 天 | #FF2020（红色脉冲） | 70px，呼吸动画 |

**边样式：**

| 类型 | 颜色 |
|------|------|
| invested_in | #5A5A5A（灰色） |
| partner_at | #B8860B（金色） |
| personal_investment | #8B4513（棕色） |

**节点图标：** 通过 Google Favicon API 获取机构/公司 Logo

### 5.3 交互功能

- **时间轴滑块：** 按年份筛选投资事件
- **点击聚焦：** 单击节点 → 高亮子图 + 显示投资时间线
- **悬停提示：** 显示节点/边的详细元数据
- **Fit View：** 自动缩放适配可见图
- **呼吸动画：** 最近 7 天的投资节点红色脉冲

### 5.4 物理引擎

- 求解器：ForceAtlas2Based
- 引力常数：-150
- 弹簧长度：250px
- 阻尼系数：0.4
- 稳定化迭代：300 次
