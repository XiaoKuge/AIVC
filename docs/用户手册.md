# AIVC 用户手册

> AI 风险投资知识图谱系统

## 1. 系统简介

AIVC 是一个基于知识图谱的 AI 风险投资关系追踪系统，用于记录和可视化 VC 机构、初创公司、投资人之间的投资关系网络。

**核心功能：**
- 追踪全球 AI 领域的 VC 投资交易
- 交互式可视化展示投资关系网络（Bloomberg 终端风格暗色主题）
- 每日自动抓取 RSS 新闻源中的融资文章
- 通过 Claude Code 智能提取交易信息（无需额外 API 密钥）
- 命令行查询：查看投资组合、共同投资者、搜索实体等
- 事件溯源：所有数据变更自动记录为事件，支持审计追踪
- 分享与导出：通过 URL 分享视图状态，导出 PNG 图片

## 3. 日常使用流程

### 3.1 整体流程图

```
GitHub Action（每日自动，无需 API 密钥）
  RSS 新闻源 → 筛选融资文章 → 抓取全文 → 保存原始文章

Claude Code 会话（使用你的订阅）
  读取原始文章 → 提取交易 → 暂存 → 审批 → 更新图谱 + 可视化
```

### 3.2 步骤一：获取最新原始文章

每日 UTC 8:00（北京时间 16:00），GitHub Action 自动运行，抓取 RSS 新闻中的融资文章，保存为原始文本。

```bash
# 拉取最新数据
git pull
```

也可以手动触发抓取：

```bash
# 本地手动抓取
python scripts/update.py --fetch

# 预览模式（不保存）
python scripts/update.py --fetch --dry-run
```

或在 GitHub 网页上：**Actions** 标签 → 选择 "Daily Article Fetch" → 点击 **"Run workflow"**

### 3.3 步骤二：提取交易信息

在 Claude Code 中，告诉我：

> "从原始文章中提取交易"

我会：
1. 读取 `data/staging/raw_articles.json`
2. 从每篇文章中提取投资方、被投公司、金额、轮次等信息
3. 将结果写入 `data/staging/pending_deals.json`

### 3.4 步骤三：审核暂存的交易

```bash
# 查看待审批的交易列表
python scripts/update.py --list
```

输出示例：
```
Staged deals: 3
    1. Sequoia Capital -> Anthropic — $2B (Series D) [2026-01-15]
    2. a16z -> Mistral AI — $600M (Series B) [2026-02-01]
    3. Tiger Global -> Scale AI — $400M (Series F)
```

如果需要编辑，可以直接修改 `data/staging/pending_deals.json`。

### 3.5 步骤四：审批并合并到图谱

```bash
# 预览（不实际保存）
python scripts/update.py --approve --dry-run

# 正式审批：合并到图谱 + 重新生成可视化
python scripts/update.py --approve
```

### 3.6 步骤五：提交更改

让我帮你提交，或者手动执行：

```bash
git add data/graph.json public/index.html data/staging/ data/snapshots/
git commit -m "chore: update graph with new deals"
git push
```

## 4. 查询功能

### 4.1 命令行查询

```bash
# 查看某 VC 的投资组合
python scripts/query_cli.py portfolio "Andreessen Horowitz (a16z)"

# 查看某公司的投资方
python scripts/query_cli.py investors "OpenAI"

# 查看共同投资关系
python scripts/query_cli.py co-investors "Sequoia Capital"

# 搜索实体（模糊匹配）
python scripts/query_cli.py search "mistral"

# 查看 VC 详情
python scripts/query_cli.py details "Khosla Ventures"

# 图谱统计
python scripts/query_cli.py stats
```

### 4.2 交互式可视化

打开 `public/index.html`（或访问 Vercel 部署地址），可以：

- **时间轴滑块**：筛选特定年份的投资
- **点击节点**：聚焦该节点的子图，显示投资历史 + 弹出事件档案面板
- **悬停查看**：显示节点/边的详细信息（暗色主题浮窗）
- **悬停呼吸光晕**：鼠标悬停时，该节点及其邻居/边以节点颜色发光脉动
- **双击节点**：打开相关网页链接
- **Fit View 按钮**：自动缩放适配当前可见图
- **Share 按钮**：将当前视图状态（聚焦节点 + 时间轴范围）编码为 URL，复制到剪贴板
- **Export PNG 按钮**：将当前画布导出为 PNG 图片下载
- **事件档案面板**：点击节点/边后在右侧弹出情报档案，以走马灯形式展示事件历史（左右箭头翻页，Escape 关闭）

**节点颜色说明：**
| 颜色 | 类型 |
|------|------|
| 橙色 | VC 机构 |
| 绿色 | 初创公司 |
| 青色 | 投资人 |
| 红色闪烁 | 最近 7 天的投资 |

| `data/snapshots/` | 图谱历史快照（每次审批前自动备份） |
| `data/raw/ai_vc_firms_worldwide.xlsx` | 原始种子数据 |

## 7. 常见问题

**Q：GitHub Action 没有自动运行？**
A：如果仓库 60 天无活动，GitHub 会自动禁用定时任务。前往 Actions 标签页手动触发一次即可恢复。

**Q：如何添加新的 RSS 源？**
A：在 `data/raw/ai_vc_firms_worldwide.xlsx` 的 "AI VC News Sources" 工作表中添加，需要填入 RSS URL。

**Q：如何修正实体名称？**
A：编辑 `data/aliases.json`，添加别名映射，例如 `"a16z": "Andreessen Horowitz (a16z)"`。

**Q：如何回滚到之前的图谱版本？**
A：从 `data/snapshots/` 中复制对应时间戳的快照到 `data/graph.json`，然后运行 `python viz/generate.py` 重新生成可视化。
